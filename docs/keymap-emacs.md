# Emacs キーマップ互換レベル（現時点）

この表は実装に基づく、ijevim の Emacs 互換状況。

## 移動

| キー/操作 | 状態 | メモ |
|---|---|---|
| `C-f` `C-b` `C-n` `C-p` | 対応済み | 文字/行移動。カウント固定（1）。 |
| `C-a` `C-e` | 対応済み | 行頭/行末。 |
| 矢印キー / Home / End / PgUp / PgDn | 対応済み | 非 Emacs 由来キーも利用可能。 |
| `M-f` `M-b` | 対応済み | 単語単位の移動。 |
| `M-v` | 対応済み | 1画面後退（PageUp相当）。 |
| `C-v` | 対応済み | 1行上スクロール（本家は1画面進む）。 |

## 挿入/削除

| キー/操作 | 状態 | メモ |
|---|---|---|
| 文字入力 / Enter / Tab | 対応済み | 直接挿入。 |
| Backspace / Delete | 対応済み | 後退/前方削除。 |
| `C-d` `C-h` | 対応済み | 前方/後退削除（Delete/Backspaceと同じ）。 |
| `C-k` | 対応済み | カーソル位置から行末まで削除（kill）。undo 対応。 |
| `C-w` | 対応済み | リージョン活性中は kill-region、非活性時は kill-word。 |
| `C-t` | 対応済み | カーソル前後の文字を入れ替え（transpose-chars）。 |

## 検索

| キー/操作 | 状態 | メモ |
|---|---|---|
| `C-s` | 一部対応 | コマンドモード (`/`) での前方検索。インクリメンタルではない。 |
| `C-r` | 対応済み | コマンドモード (`?`) での後方検索。 |

## 保存/終了

| キー/操作 | 状態 | メモ |
|---|---|---|
| `C-x C-s` | 対応済み | 保存。 |
| `C-x C-c` | 対応済み | 終了（dirty時は確認）。 |
| `C-o` | 対応済み | 保存（本家は open-line）。互換性維持のための独自割当。 |

## Undo/Redo

| キー/操作 | 状態 | メモ |
|---|---|---|
| `C-/` `C-_` `C-?` | 対応済み | Undo。 |
| `C-x u` | 対応済み | Redo。 |
| `C-x C-/` | 対応済み | Redo（別名）。 |

## 選択・ヤンク

| キー/操作 | 状態 | メモ |
|---|---|---|
| `C-space` (`C-@`) | 対応済み | マーク設定。 |
| `C-w` (region active) | 対応済み | リージョン削除 + kill-ring 保存。 |
| `M-w` | 対応済み | リージョンコピー（削除なし）。 |
| `C-y` | 対応済み | kill-ring の最新エントリをヤンク。 |
| `M-y` | 対応済み | kill-ring をサイクル（yank-pop）。 |

## 画面 / その他

| キー/操作 | 状態 | メモ |
|---|---|---|
| `C-l` | 対応済み | 画面クリア＋カーソル行を中央に。 |
| `C-g` | 対応済み | 現在のコマンド/リージョンをアボート。 |
| `C-x h` | 対応済み | カーソルを行頭へ（本家は select-all）。 |
| `C-x d` | 対応済み | カーソルを行末へ（本家は list-directory）。 |

## 凡例

- 対応済み: 完全に実装済み
- 一部対応: 基本動作はするが本家と異なる部分あり
- 未対応: 未実装
