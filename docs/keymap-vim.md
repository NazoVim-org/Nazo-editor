# Vim キーマップ互換レベル（現時点）

この表は実装に基づく、ijevim の Vim 互換状況。

## 移動

| キー/操作 | 状態 | メモ |
|---|---|---|
| `h` `j` `k` `l` | 対応済み | カウント接頭辞対応 (`3j`)。 |
| `w` `b` `e` | 対応済み | 単語移動。カウント対応。 |
| `0` `^` `$` | 対応済み | `^` は空白以外の最初の文字へ。`$` は行末＋カウント(下のN行目の行末)に対応。 |
| `gg` / `G` | 対応済み | `gg` は先頭行。`G` は最終行。カウント付き `G` は指定行。 |
| `%` | 対応済み | 対応括弧へジャンプ。 |
| `f` `F` `t` `T` `;` `,` | 対応済み | 1文字検索移動と繰り返し。 |

## 挿入/削除

| キー/操作 | 状態 | メモ |
|---|---|---|
| `i` `a` `A` `o` `O` | 対応済み | Insert モード遷移。 |
| `R` | 対応済み | Replace モード。 |
| `r` | 対応済み | 1文字置換 → Normal 復帰。 |
| `x` | 対応済み | 1文字削除（カウント対応）。 |
| `dd` `dw` `diw` `daw` | 対応済み | 演算子経由で実装。テキストオブジェクト: `w`, `"`, `'`, `(`, `)`, `b`, `[`, `]`, `{`, `}`, `B`, `<`, `>`。 |
| `cc` `cw` `ciw` `caw` | 対応済み | change 演算子。同上のテキストオブジェクト。 |
| `D` | 対応済み | カーソル位置から行末まで削除。 |
| `C` | 対応済み | カーソル位置から行末まで削除し Insert モードへ。 |
| `S` | 対応済み | 行全体を削除し Insert モードへ。 |
| `s` | 対応済み | 1文字削除し Insert モードへ。 |

## 検索

| キー/操作 | 状態 | メモ |
|---|---|---|
| `/` | 対応済み | 前方検索。 |
| `?` | 対応済み | 後方検索。 |
| `*` | 対応済み | カーソル下単語検索。 |
| `n` `N` | 対応済み | 次/前検索。方向反転対応。 |

## 保存/終了

| キー/操作 | 状態 | メモ |
|---|---|---|
| `:w` | 対応済み | 保存。 |
| `:q` | 対応済み | 変更あり時は確認表示。 |
| `:wq` `:x` `ZZ` | 対応済み | 保存して終了。 |
| `:q!` | 対応済み | 破棄終了。 |
| `:e` `:e!` | 対応済み | ファイル再読込。 |
| `:wqa` `:wa` `:qa` | 対応済み | 全バッファ操作（単一バッファのみ）。 |
| `ZQ` | 対応済み | 保存せず終了（q! 相当）。 |
| `:w <path>` / `:wq <path>` | 対応済み | 名前を付けて保存/保存終了。 |

## Undo/Redo

| キー/操作 | 状態 | メモ |
|---|---|---|
| `u` | 対応済み | Undo（最大1000件）。 |
| `Ctrl-r` | 対応済み | Redo。 |
| `.` | 対応済み | 直前の挿入/削除/変更を繰り返し。 |

## 選択・ヤンク

| キー/操作 | 状態 | メモ |
|---|---|---|
| `v` `V` | 対応済み | Visual character/line。 |
| `Ctrl-v` | 対応済み | Visual block（矩形選択）。`d`/`y`/`c`/`I`/`A` 対応。 |
| `y` `yy` `yw` `ye` | 対応済み | yank 演算子。 |
| `p` `P` | 対応済み | 貼り付け（行/文字列自動判定）。 |
| テキストオブジェクト | 対応済み | `iw` `aw` `i"` `a"` `i'` `a'` `i(` `a(` `ib` `ab` `i[` `a[` `i{` `a{` `iB` `aB` `i<` `a<` `i>` `a>`。 |

## レジスタ / マーク / マクロ

| キー/操作 | 状態 | メモ |
|---|---|---|
| `"a-"`z` | 対応済み | 名前付きレジスタ指定。 |
| `"+` | 対応済み | システムクリップボード（`arboard`）。 |
| `m{a-z}` / `` `{a-z} `` ` `'{a-z}` | 対応済み | マーク設定/ジャンプ。 |
| `q{a-z}` / `@{a-z}` | 対応済み | マクロ録音/再生。 |
